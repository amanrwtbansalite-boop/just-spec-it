# Security Policy

## Supported version

Security fixes are applied to the latest released version.

## Report a vulnerability

Please use GitHub's private vulnerability reporting for this repository. Do not open a public issue for a suspected vulnerability and do not include credentials or private project content in any report.

Include the affected version, impact, reproduction steps, and any suggested mitigation. You should receive an acknowledgement within seven days.

## Data handling

Just Spec It does not include telemetry. It sends only the context shown in its preview to the model provider selected by the user. The default context includes a bounded directory tree, README, common manifest files, the requirement, and existing spec documents needed by the requested operation.

Users should inspect that preview and their chosen provider's data policy before sending sensitive repository information.
